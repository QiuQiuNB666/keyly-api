# 合规 AI API 中转站方案（只出方案，未部署）

2026-11-27 · 资料都是当天从 GitHub 和各家官网核实的，引文附出处。

---

## 0. 先说结论（看这一段就够）

**"接官方 API Key 再转卖"这条路，对 Claude、GPT、OpenRouter 也不合规。** 三家条款都写明禁止转售 API 访问，而且中国大陆、香港都不在 Anthropic 和 OpenAI 的服务地区里（原文见 §2）。所以原来设想的"合规版 = 官方 Key + new-api"，上游只要是这三家，就照样违规、照样会被封号。

**真正能合规做的只有一种：上游只接国产模型**（DeepSeek、阿里云百炼的千问等），再加上：
- 网关用 **new-api**（§1）
- 先租一台**境外小 VPS**（§3）
- Keyly 卖**额度兑换码**，第一版 **Keyly 一行代码都不用改**（§4）
- 毛利 20–30%（§5）
- 面向公众开放之前要去属地网信办办**生成式 AI 应用登记**（§6）

**生意上要说实话**：国产模型官方本来就便宜，国内用户直接用支付宝就能充值。中转站这一行的需求主要来自"国内买不到 Claude/GPT"，而这正好是合规版不能做的部分。合规版能卖的只有"一个 Key 能调多家模型、开发票省事、量小也能买"，客群小，赚的是辛苦钱。**要不要做，请先看 §7 第 1 条。**

## 2. 上游渠道

### 2.1 各家条款里关于转售的写法（原文）

| 上游 | 能不能转售 | 原文 | 出处 |
|---|---|---|---|
| **Anthropic** | ❌ 除非书面批准 | "Customer may not … resell the Services except as expressly approved by Anthropic" | anthropic.com/legal/commercial-terms（Use Restrictions） |
| Anthropic 服务地区 | ❌ 大陆、港澳都不在列 | 下面两种情况都不允许："Use by persons while physically located in an unsupported region"，以及 "Use by entities that are majority-owned or controlled … by persons or entities in unsupported regions" | anthropic.com/legal/supported-regions |
| **OpenAI** | ❌ 能做成自己的应用给用户用，但不能卖 Key、不能转租账号 | "Customer may not resell or lease access to its Account"；"(g) buy, sell, or transfer API keys from, to, or with a third party"；"may not access or offer access to the Services outside of the Supported Countries and Territories" | openai.com/policies/services-agreement（2025-12-01 版） |
| **OpenRouter** | ❌ 明文禁止 | "access the Site or Service for purposes of reselling API access to Models or otherwise developing a competing service" | openrouter.ai/terms |
| **Gemini** | ❌ 地区不支持 | "You may only access the Services (or make API Clients available to users) within an available region"（中国大陆不在可用地区里） | ai.google.dev/gemini-api/terms |
| **DeepSeek** | ⚠️ 没看到明文禁止转售，但不准共享 Key | "2.4 … 不要与他人共享或对外公开您的API key"；"6.3 … 符合退款要求的…扣除手续费用等必要成本后退回剩余全部未消费的充值金额" | cdn.deepseek.com/policies/zh-CN/deepseek-open-platform-terms-of-service.html |
| **阿里云百炼（千问）** | ✅ 有官方分销通道 | 阿里云有"AI 大模型销售与服务生态合作计划"（标准、领先、旗舰三级） | partner.aliyun.com/program/aimsp |

**怎么理解**：网关把 Key 放在服务器上，买家拿到的是 new-api 发的 Key，不是 DeepSeek 的 Key，所以不算"共享 Key"。但 DeepSeek 的协议没有正面写可以转售，**正式卖之前要发邮件拿到书面确认**。百炼走合作伙伴计划最稳，是官方认可的分销身份。

## 4. 和 Keyly 怎么打通

### 第一版：Keyly 不改代码，只加商品
1. 在 new-api 后台 → 兑换码 → 批量生成，例如 100 张面额 ¥50 的码，导出成文本。
2. 在 Keyly 后台新建商品"AI API 额度 ¥50"（普通卡密发货，`pickup_here=0`），用现有的"导入卡密"功能（`src/app/admin/actions.ts:339 importCards`）把码粘进去。
3. 买家在 Keyly 付款后拿到码，到中转站的"钱包 → 兑换"里充值。

**Keyly 要改的只有数据**：新商品、分类、说明文案、常见问题加一条"怎么兑换"。代码不用动。

### 第二版（卖得动再做）
- **自动补货**：库存少于 N 张时，Keyly 用 new-api 的管理 access token（只给兑换码权限）调接口生成一批码，再写进 `cards` 表。改动：Keyly 加一个定时任务和一个设置项（new-api 地址、token），大约一个文件。
- **账号打通**（买家在 Keyly 付完款，额度自动进中转站账号）：要改订单回调、加用户映射。**没有需求之前不做。**

### 注意
- 链动小铺禁止商品名带 GPT/ChatGPT 等词。写"DeepSeek / 千问 API 额度"没问题。
- 面额建议 ¥10、¥50 两档：小额好试用，也符合"个人申请支付宝网站支付单笔 ≤50 元"的限制。

## 5. 定价和利润

假设一笔典型用量：**输入 100 万 token（不算缓存）+ 输出 25 万 token**。成本统一按**高峰价**算（保守），售价 = 成本 × 倍率（在 new-api 里用"分组倍率"设置）。手续费按链动小铺 3% 算。将来改成支付宝网站支付，手续费约 0.6%（以签约费率为准）；USDT 约为 0。

| 模型 | 成本 | 倍率 | 售价 | 手续费 3% | **毛利** | 毛利率 |
|---|---|---|---|---|---|---|
| deepseek-flash | 2 + 8×0.25 = **4.00** | 1.5× | 6.00 | 0.18 | **1.82** | 30% |
| deepseek-v4-pro | 9 + 27×0.25 = **15.75** | 1.3× | 20.48 | 0.61 | **4.12** | 20% |
| qwen-plus | 0.8 + 2×0.25 = **1.30** | 1.5× | 1.95 | 0.06 | **0.59** | 30% |

算法：`毛利 = 成本×倍率×(1 − 手续费率) − 成本`。

- 更正（11-27 读源码确认）：new-api 自带 DeepSeek 高峰/空闲两档计价（`setting/billing_setting/builtin_billing.go`），买家在空闲时段用会自动按半价扣，倍率照乘，毛利率不变。
- 命中缓存的请求成本只有原价的 2–3%。new-api 支持单独设缓存价，**缓存价也要乘倍率**，否则会亏。
- 汇率：上游全是人民币，收款也是人民币，不涉及汇率。只有 USDT 收款要按当天汇率换算，波动由我们承担。
- 一张 ¥50 的码，大约能赚 ¥10–15（毛利，没扣服务器费）。服务器 ¥50/月，要卖 4–5 张才回本。

## 6. 风险和应对

| 风险 | 应对 |
|---|---|
| **上游封 Key、停服** | 每家至少挂两个 Key，或者两家互为备份（new-api 渠道权重 + 自动重试）；上游余额只充够 1–2 周的用量，封了也不会一次亏很多。 |
| **预付余额的责任** | 买家的余额就是我们欠的钱。兑换码设有效期（例如 1 年）；在页面写清楚退款规则，照抄 DeepSeek 的"未消费部分扣手续费退回"；上游余额要始终 ≥ 买家没用完的总余额。 |
| **内容合规** | 上游自带审核；new-api 打开敏感词检查（上线前实测）；调用日志至少留 6 个月（网络安全法要求）；注册时绑手机号做实名。 |
| **境内登记和备案** | 网信办公告原文："对于通过API接口或其他方式直接调用已备案模型能力的生成式人工智能应用或功能，由地方网信办开展登记"，而且要"在显著位置…公示…模型名称、备案号或上线编号"（江苏网信 2026-11-20 公告）。今年 4 月起"清朗·整治 AI 应用乱象"已经在执法。**面向公众开放之前要先登记**。服务器放国内还要 ICP 备案；记忆里查过，支付宝网站支付也要 ICP 备案。只给固定的企业客户或团队内部用、不公开招揽，可能不算"向公众提供"，**这一点要问律师**。 |
| **AGPL** | 不改 new-api 源码；要改就把修改公开。 |

## 7. 需要用户拍板的事

1. **上游只有国产模型（DeepSeek、千问），没有 Claude 和 GPT，还做不做？** 不做的话，到这里就停。
2. **用谁的名义做**：个人，还是诚一的公司？这决定了上游能不能做企业认证、能不能进百炼伙伴计划、生成式 AI 登记和 ICP 用谁的主体去办。
3. **先公开卖，还是先只给熟人或企业客户用？** 公开卖要先办登记；只给熟人或企业客户用可以先跑起来，但要律师确认。
4. **部署用境外 VPS（推荐，约 ¥30–70/月）**，同意的话我再去比价、挑商家。
5. **定价**：倍率 1.3–1.5×，面额 ¥10 和 ¥50，可以吗？
